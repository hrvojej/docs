# S016 — D001 Portfolio Execution Roadmap

## Milestone
The six-opportunity public research program was already complete.

This session translated O001–O006 into an execution portfolio.

## Portfolio structure
- O001: commercialize existing TMS/service capability.
- O004: internal productivity/capacity track.
- O005/O006: strategic product-development track.
- O002/O003: partner-enabled service track.

## Main execution rule
Do not start six equal programs and do not build a generic AI/robotics platform first.

Develop only where:
1. a customer pays additional money;
2. a factory demonstrably ships more accepted product; or
3. lifecycle cost/risk is demonstrably reduced.

## First sequence
0–90 days:
- package O001;
- run one-cell/process O004 proof.

3–9 months:
- narrow O005 rail/tram digital/ADAS product;
- narrow O006 renewable/BESS performance product.

Parallel only on demand:
- O002 grid inspection;
- O003 hydro inspection.

## Architecture implication
Share asset identity, telemetry, events, evidence, work-order integration and audit primitives when two production products require them.

Do not centralize domain control/safety logic prematurely.
